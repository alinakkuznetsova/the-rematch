# The Rematch: Restaging Deep Blue vs Kasparov, Game 6

Information about navigating this portfolio:

**Critical-reflection.md** is the main file and contains all non-technical requirements: the write-up of the piece, the system and how it works, the technical problems I solved, both performances, the audience feedback, and a critical reflection.

The code can be found in the **chess_code** folder.

The documentation images are in the **media** folder, but they are embedded throughout Critical-reflection.md, along with the performance videos (linked to OneDrive), so the reflection is best read in full rather than viewing the media separately.
